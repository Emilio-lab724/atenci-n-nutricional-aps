# Atención Nutricional APS

Herramienta académica de práctica para estudiantes de Nutrición y Dietética (USS). Usar solo datos ficticios o anonimizados; no reemplaza el juicio profesional.

Sitio estático (HTML + JS + `data/`). Sin build. Los pacientes se guardan en el navegador (localStorage); use Exportar/Importar JSON para moverlos.
